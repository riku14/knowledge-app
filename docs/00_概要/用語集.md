# 用語集

## 1. 概要

ナレッジ共有アプリケーションで使用される用語の定義集です。

## 2. 基本用語

| 用語 | 英語 | 説明 |
|------|------|------|
| ナレッジ | Knowledge | 知識、情報 |
| 記事 | Article | ナレッジを記述した文書 |
| カテゴリ | Category | 記事の大分類（技術ドキュメント、業務マニュアル、FAQ） |
| タグ | Tag | 記事の分類用ラベル（複数付けられる） |
| コメント | Comment | 記事に対するコメントや質問 |
| お気に入り | Favorite | ユーザーがブックマークした記事 |

## 3. ユーザー・権限関連

| 用語 | 英語 | 説明 |
|------|------|------|
| 管理者 | Admin | 全機能へのアクセス権限を持つユーザー |
| チームリーダー | Leader | タグ管理と記事承認ができるユーザー |
| 一般ユーザー | Member | 基本的な機能のみ利用できるユーザー |
| 権限 | Role | ユーザーが持つ権限の種類（admin/leader/member） |
| チーム | Team | 複数のユーザーで構成されるグループ |
| チームリーダー | Team Leader | チームを管理するユーザー |

## 4. 記事関連

| 用語 | 英語 | 説明 |
|------|------|------|
| 公開範囲 | Scope | 記事の公開範囲（public=全体公開、team=チーム限定） |
| 全体公開 | Public | 全社員が閲覧可能な記事 |
| チーム限定 | Team Limited | 特定のチームのみ閲覧可能な記事 |
| ステータス | Status | 記事の状態（draft=下書き、pending=承認待ち、published=公開済み、rejected=差し戻し） |
| 下書き | Draft | 投稿前の記事 |
| 承認待ち | Pending | 全体公開記事で承認を待っている状態 |
| 差し戻し | Rejection | 承認申請が却下され、下書きに戻された状態 |
| 差し戻し理由 | Rejection Reason | 差し戻し時に記入される理由 |

## 5. 機能関連

| 用語 | 英語 | 説明 |
|------|------|------|
| Markdown | Markdown | 軽量マークアップ言語 |
| プレビュー | Preview | マークダウンをHTMLに変換した表示 |
| フィルター | Filter | 条件で記事を絞り込む機能 |
| ソート | Sort | 記事の並び替え（新着順、古い順等） |
| ページネーション | Pagination | ページ分割表示 |
| 検索 | Search | キーワードで記事を検索する機能 |
| 検索対象 | Search Target | 検索を行う対象（タイトル、本文、タグ、投稿者） |

## 6. UI/UX関連

| 用語 | 英語 | 説明 |
|------|------|------|
| サイドバー | Sidebar | 画面左側のナビゲーションメニュー |
| ヘッダー | Header | 画面上部のバー |
| パンくずリスト | Breadcrumb | 現在位置を示すナビゲーション |
| モーダル | Modal | オーバーレイ表示されるダイアログ |
| トースト通知 | Toast Notification | 一時的に表示される通知メッセージ |
| レスポンシブ | Responsive | 画面サイズに応じてレイアウトが変わるデザイン |

## 7. 技術関連

| 用語 | 英語 | 説明 |
|------|------|------|
| SPA | Single Page Application | シングルページアプリケーション |
| API | Application Programming Interface | アプリケーション間の通信インターフェース |
| RESTful API | RESTful API | REST原則に基づいたAPI設計 |
| JWT | JSON Web Token | 認証に使用するトークン形式 |
| ハッシュ化 | Hashing | パスワード等を不可逆的に変換すること |
| XSS | Cross-Site Scripting | クロスサイトスクリプティング攻撃 |
| CSRF | Cross-Site Request Forgery | クロスサイトリクエストフォージェリ攻撃 |
| SQLインジェクション | SQL Injection | データベースへの不正なSQL文の注入 |

## 8. データベース関連

|------|------|------|
