# ナレッジ共有アプリケーション 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
ナレッジ共有アプリケーション

### 1.2 目的
企業やチーム内でのナレッジ共有を促進し、情報の属人化を防ぐ。組織全体の知識を一元管理し、効率的な情報共有を実現する。

### 1.3 対象ユーザー
- 企業の従業員（全社員）
- チームメンバー
- 管理者・チームリーダー

### 1.4 プロジェクト期間
- 開発期間: 2024年10月〜2024年12月
- リリース予定: 2024年12月

---

## 2. システム概要

### 2.1 システムアーキテクチャ
- **種別**: シングルページアプリケーション（SPA）
- **フロントエンド**: React 18（CDN版）
- **スタイリング**: Tailwind CSS
- **データ管理**: クライアントサイド（モックデータ）
- **将来的な拡張**: RESTful API + バックエンドサーバー

### 2.2 技術スタック
| カテゴリ | 技術 | バージョン/説明 |
|---------|------|----------------|
| UI フレームワーク | React | 18.x |
| スタイリング | Tailwind CSS | 最新版 |
| Markdown パーサー | Marked.js | 9.1.5 |
| シンタックスハイライト | Prism.js | 1.29.0 |
| アイコン | Font Awesome | 6.4.0 |
| フォント | Google Fonts (Noto Sans JP) | - |

### 2.3 対応デバイス・ブラウザ
#### デバイス
- PC（1024px以上）
- タブレット（768px〜1023px）
- スマートフォン（767px以下）

#### ブラウザ
- Google Chrome（最新版）
- Firefox（最新版）
- Safari（最新版）
- Microsoft Edge（最新版）

## 3. 機能要件

### 3.1 ユーザー権限

#### 3.1.1 管理者（Admin）
- **権限内容**:
  - 全機能へのアクセス
  - ユーザー管理（作成・編集・削除）
  - チーム管理（作成・編集・閉鎖・再開）
  - タグ管理（作成・編集・削除）
  - 全体公開記事の承認・差し戻し
  - 全記事の閲覧・作成・編集・削除
  - コメント投稿・削除

#### 3.1.2 チームリーダー（Leader）
- **権限内容**:
  - タグ管理（作成・編集・削除）
  - 全体公開記事の承認・差し戻し
  - 所属チーム内記事の作成・編集・削除
  - 全記事の閲覧
  - お気に入り管理
  - コメント投稿・削除

#### 3.1.3 一般ユーザー（Member）
- **権限内容**:
  - 公開記事の閲覧
  - 所属チーム内記事の作成・編集
  - 自分の記事の削除
  - お気に入り管理
  - コメント投稿
  - 自分のコメントの削除

### 3.2 認証機能

#### 3.2.1 ログイン
- **入力項目**:
  - ユーザーID（必須）
  - パスワード（必須）
- **機能**:
  - 認証処理
  - パスワード表示/非表示切り替え
  - エラーメッセージ表示
- **備考**: デモ版では任意のID/パスワードでログイン可能

#### 3.2.2 ログアウト
- **機能**:
  - ヘッダーのユーザーメニューからログアウト
  - 確認ダイアログ表示
  - ログイン画面への遷移

### 3.3 ホーム画面

#### 3.3.1 ウェルカムセクション
- **表示内容**:
  - ユーザー名を含むウェルカムメッセージ
  - クイック統計（4項目）
    - 公開記事数
    - お気に入り数
    - 下書き数
    - タグ数

#### 3.3.2 最近の投稿
- **表示内容**:
  - 最新10件の公開記事
  - 記事カード形式で表示
  - 「すべて見る」リンク

#### 3.3.3 サイドバー情報
- **カテゴリ別記事数**:
  - 円グラフまたはリスト表示
  - 各カテゴリの記事数
- **人気のタグクラウド**:
  - タグ名とサイズ（使用頻度による）
  - クリックで検索
- **クイックアクション**:
  - 新規記事作成
  - 下書きを確認
  - お気に入り

### 3.4 記事管理機能

#### 3.4.1 記事一覧
- **表示内容**:
  - 記事カード（タイトル、カテゴリ、タグ、投稿者、日付、公開範囲）
  - お気に入りアイコン
- **フィルター機能**:
  - カテゴリフィルター
  - タグフィルター
  - 並び替え（新着順、古い順、更新日順、人気順）
- **ページネーション**:
  - 10件/ページ
  - ページ番号表示（1-10）
  - 前へ/次へボタン
- **その他**:
  - チーム記事一覧では「新規記事作成」ボタン表示

#### 3.4.2 記事詳細
- **ヘッダー部**:
  - カテゴリバッジ
  - タグ一覧
  - タイトル（大見出し）
  - 投稿者情報（アバター、名前）
  - 投稿日時・更新日時
  - 公開範囲バッジ
- **アクションボタン**:
  - お気に入り追加/削除
  - 編集（投稿者のみ）
  - 削除（投稿者のみ）
- **本文エリア**:
  - Markdownレンダリング
  - シンタックスハイライト（コードブロック）
  - 見出し階層構造
  - リスト表示
  - テーブル表示
  - 引用表示
- **コメントエリア**:
  - コメント一覧（投稿者、日時、内容）
  - コメント削除ボタン（投稿者または記事作者）
  - コメント入力欄
  - コメント投稿ボタン

#### 3.4.3 記事作成・編集
- **レイアウト**:
  - PC: 2カラム（左：入力、右：プレビュー）
  - モバイル: タブ切り替え（入力/プレビュー）

- **入力項目**:
  - **タイトル**（必須）
    - 1行テキスト入力
  - **カテゴリ**（必須）
    - ドロップダウン選択
    - 選択肢: 技術ドキュメント、業務マニュアル、FAQ
  - **タグ**（任意）
    - 複数選択可能
    - 既存タグから選択
  - **公開範囲**（必須）
    - ラジオボタン選択
    - 全体公開（承認必要）: 全社員が閲覧可能、管理者承認が必要
    - チーム内限定: 選択したチーム内のみ閲覧可能
  - **チーム選択**（チーム内限定時のみ必須）
    - ドロップダウン選択
    - 所属チームのみ表示
  - **本文**（必須）
    - Markdownエディタ
    - ツールバー付き（見出し、太字、斜体、コード、リスト等）

- **プレビュー機能**:
  - リアルタイムプレビュー
  - Markdownレンダリング結果を表示
  - シンタックスハイライト適用

- **アクションボタン**:
  - 下書き保存
  - 投稿（チーム内限定）/承認申請（全体公開）
  - キャンセル

- **バリデーション**:
  - タイトル: 必須、空白不可
  - 本文: 必須、空白不可
  - カテゴリ: 必須
  - チーム: チーム内限定時必須

#### 3.4.4 下書き一覧
- **表示内容**:
  - 自分の下書き記事一覧
  - 記事カード形式
  - 差し戻し記事は差し戻しバッジ表示
  - 差し戻し理由表示
- **アクション**:
  - 記事カードクリックで詳細表示
  - 編集ボタン
  - 削除ボタン

#### 3.4.5 承認待ち一覧（管理者・リーダーのみ）
- **表示内容**:
  - 承認待ち記事一覧
  - カテゴリ、タグ、タイトル
  - 投稿者、投稿日、公開先
- **アクション**:
  - プレビューボタン
  - 承認ボタン
  - 差し戻しボタン
- **差し戻し処理**:
  - 差し戻し理由入力モーダル表示
  - 理由は必須入力
  - 送信で下書きに戻る

### 3.5 検索機能

#### 3.5.1 基本検索
- **検索バー**:
  - サイドバー上部に配置
  - キーワード入力
  - Enterキーで検索実行

#### 3.5.2 詳細検索
- **検索対象選択**（複数選択可）:
  - タイトル
  - 本文
  - タグ
  - 投稿者

- **フィルター**:
  - カテゴリ
  - 公開範囲（全体公開/チーム限定）
  - 日付範囲（開始日〜終了日）

- **検索結果表示**:
  - 検索キーワード表示
  - ヒット件数表示
  - 記事カード一覧
  - キーワードハイライト（オプション）

### 3.6 お気に入り機能

#### 3.6.1 お気に入り追加/削除
- **操作方法**:
  - 記事カードまたは記事詳細のスターアイコンクリック
  - トグル動作（追加⇔削除）
  - トースト通知表示

#### 3.6.2 お気に入り一覧
- **表示内容**:
  - お気に入り登録した記事一覧
  - 記事カード形式
- **フィルター**:
  - カテゴリ
  - タグ
- **ソート**:
  - 登録日順（新しい順）

### 3.7 チーム機能

#### 3.7.1 チーム一覧（サイドバー）
- **表示内容**:
  - 所属チーム一覧
  - チーム名
  - 展開/折りたたみ可能
- **アクション**:
  - チーム名クリックでチーム記事一覧へ遷移

#### 3.7.2 チーム記事一覧
- **表示内容**:
  - 選択したチームの記事一覧
  - 記事カード形式
- **機能**:
  - 記事一覧機能と同様
  - 新規記事作成ボタン（チームメンバーのみ）

### 3.8 管理機能

#### 3.8.1 タグ管理（管理者・リーダー）
- **タグ一覧**:
  - テーブル形式で表示
  - 列: タグ名、記事数、操作
- **新規タグ作成**:
  - 「+ 新規タグ作成」ボタン
  - モーダルでタグ名入力
  - 作成/キャンセルボタン
- **タグ編集**:
  - 編集ボタンクリック
  - モーダルでタグ名編集
  - 保存/キャンセルボタン
- **タグ削除**:
  - 削除ボタンクリック
  - 確認ダイアログ表示
  - 使用中の場合は警告表示

#### 3.8.2 チーム管理（管理者のみ）
- **チーム一覧**:
  - テーブル形式で表示
  - 列: チーム名、リーダー、メンバー数、状態、操作
- **新規チーム作成**:
  - 「+ 新規チーム作成」ボタン
  - モーダルで入力
    - チーム名（必須）
    - チームリーダー選択（必須）
    - メンバー選択（複数選択）
    - 公開フラグ（チェックボックス）
  - 作成/キャンセルボタン
- **チーム編集**:
  - 編集ボタンクリック
  - モーダルで編集
  - 保存/キャンセルボタン
- **チーム閉鎖**:
  - 閉鎖ボタンクリック
  - 確認ダイアログ表示
  - 閉鎖済みチーム一覧へ移動
- **チーム再開**:
  - 閉鎖済みチーム一覧から再開可能
  - 再開ボタンクリック
  - アクティブチームに復帰

#### 3.8.3 ユーザー管理（管理者のみ）
- **ユーザー一覧**:
  - テーブル形式で表示
  - 列: ユーザー（アバター・名前）、メールアドレス、権限、登録日、操作
- **新規ユーザー作成**:
  - 「+ 新規ユーザー作成」ボタン
  - モーダルで入力
    - ユーザー名（必須）
    - メールアドレス（必須）
    - パスワード（必須、新規のみ）
    - 権限選択（必須）: 管理者/チームリーダー/一般
  - 作成/キャンセルボタン
- **ユーザー編集**:
  - 編集ボタンクリック
  - モーダルで編集（パスワード以外）
  - 保存/キャンセルボタン
- **ユーザー削除**:
  - 削除ボタンクリック
  - 確認ダイアログ表示

### 3.9 共通UI機能

#### 3.9.1 サイドバー
- **構成**:
  - ロゴ/アプリ名
  - 検索バー
  - 新規記事作成ボタン（常に表示）
  - ナビゲーションメニュー
  - 所属チーム一覧（展開/折りたたみ）
  - ユーザー情報表示
- **動作**:
  - デスクトップ: 常に表示、開閉可能
  - モバイル: デフォルト非表示、オーバーレイ表示

#### 3.9.2 ヘッダー
- **構成**:
  - ハンバーガーメニュー（モバイル）
  - パンくずリスト
  - ユーザーアイコン + ドロップダウンメニュー
- **ユーザーメニュー**:
  - ユーザー情報表示
  - マイページへ遷移
  - ログアウト

#### 3.9.3 通知システム
- **トースト通知**:
  - 成功: 緑色
  - エラー: 赤色
  - 情報: 青色
  - 警告: 黄色
- **表示位置**: 画面右上
- **表示時間**: 3秒間
- **アニメーション**: スライドイン/フェードアウト

#### 3.9.4 モーダルダイアログ
- **種類**:
  - 入力モーダル（作成・編集）
  - 確認モーダル（削除等）
  - 表示モーダル（画像拡大等）
- **サイズ**: sm（小）、md（中）、lg（大）、xl（特大）
- **機能**:
  - オーバーレイ表示
  - ESCキーで閉じる
  - オーバーレイクリックで閉じる
  - 閉じるボタン

## 4. 非機能要件

### 4.1 パフォーマンス
- **ページ読み込み時間**: 3秒以内
- **画面遷移**: スムーズに実行（遅延なし）
- **レスポンシブ動作**: 各デバイスで適切に表示

### 4.2 ユーザビリティ
- **直感的な操作**: 初めてのユーザーでも迷わず使える
- **一貫性**: 全画面で統一されたデザイン・操作
- **フィードバック**: ユーザー操作に対する適切なフィードバック

### 4.3 アクセシビリティ
- **キーボード操作**: 主要機能はキーボードで操作可能
- **色のコントラスト**: WCAG 2.1 AA準拠
- **スクリーンリーダー対応**: 主要要素にARIAラベル設定

### 4.4 セキュリティ
- **XSS対策**: ユーザー入力のサニタイゼーション
- **CSRF対策**: 将来のバックエンド実装時に対応
- **認証トークン管理**: 将来のバックエンド実装時に対応

### 4.5 保守性
- **コードの可読性**: コメント、命名規則の統一
- **コンポーネント化**: 再利用可能なコンポーネント設計
- **ドキュメント**: README、要件定義書の整備

## 5. データモデル

### 5.1 ユーザー（User）
```javascript
{
  id: String,              // ユーザーID（UUID）
  name: String,            // ユーザー名
  email: String,           // メールアドレス
  role: String,            // 権限（admin/leader/member）
  createdAt: String,       // 登録日（YYYY-MM-DD）
  avatar: String           // アバターURL
}
```

### 5.2 チーム（Team）
```javascript
{
  id: String,              // チームID
  name: String,            // チーム名
  leader: String,          // リーダーID（User.id）
  members: Array<String>,  // メンバーID配列（User.id）
  status: String,          // 状態（active/closed）
  public: Boolean          // 公開フラグ
}
```

### 5.3 カテゴリ（Category）
```javascript
{
  id: String,              // カテゴリID
  name: String,            // カテゴリ名
  color: String            // 色（blue/green/purple）
}
```

### 5.4 タグ（Tag）
```javascript
{
  id: String,              // タグID
  name: String,            // タグ名
  count: Number            // 使用記事数
}
```

### 5.5 記事（Article）
```javascript
{
  id: String,              // 記事ID
  title: String,           // タイトル
  content: String,         // 本文（Markdown形式）
  categoryId: String,      // カテゴリID（Category.id）
  tags: Array<String>,     // タグID配列（Tag.id）
  authorId: String,        // 投稿者ID（User.id）
  teamId: String | null,   // チームID（Team.id、全体公開時はnull）
  scope: String,           // 公開範囲（team/public）
  status: String,          // ステータス（draft/pending/published/rejected）
  createdAt: String,       // 作成日時（ISO 8601形式）
  updatedAt: String,       // 更新日時（ISO 8601形式）
  favoriteBy: Array<String>, // お気に入りユーザーID配列
  comments: Array<Comment>,  // コメント配列
  rejectionReason: String | null  // 差し戻し理由
}
```

### 5.6 コメント（Comment）
```javascript
{
  id: String,              // コメントID
  articleId: String,       // 記事ID（Article.id）
  userId: String,          // 投稿者ID（User.id）
  content: String,         // 内容
  createdAt: String        // 投稿日時（ISO 8601形式）
}
```

## 6. 画面遷移図

```
ログイン画面
    ↓
ホーム画面 ←→ 記事一覧（全体記事）
    ↓           ↓
    ↓       記事詳細 ←→ 記事編集
    ↓           ↓
    ↓       コメント投稿
    ↓
    ├→ チーム記事一覧 → 記事詳細
    ├→ お気に入り一覧 → 記事詳細
    ├→ 下書き一覧 → 記事編集
    ├→ 承認待ち一覧 → 記事詳細 → 承認/差し戻し
    ├→ 検索結果 → 記事詳細
    ├→ 記事作成 → プレビュー → 投稿
    ├→ タグ管理 → タグ作成/編集/削除
    ├→ チーム管理 → チーム作成/編集/閉鎖
    └→ ユーザー管理 → ユーザー作成/編集/削除
```

## 7. API仕様（将来実装）

### 7.1 認証API
- `POST /api/auth/login` - ログイン
- `POST /api/auth/logout` - ログアウト
- `GET /api/auth/me` - ログインユーザー情報取得

### 7.2 記事API
- `GET /api/articles` - 記事一覧取得
- `GET /api/articles/:id` - 記事詳細取得
- `POST /api/articles` - 記事作成
- `PUT /api/articles/:id` - 記事更新
- `DELETE /api/articles/:id` - 記事削除
- `POST /api/articles/:id/favorite` - お気に入り追加
- `DELETE /api/articles/:id/favorite` - お気に入り削除
- `POST /api/articles/:id/approve` - 記事承認
- `POST /api/articles/:id/reject` - 記事差し戻し

### 7.3 コメントAPI
- `GET /api/articles/:id/comments` - コメント一覧取得
- `POST /api/articles/:id/comments` - コメント投稿
- `DELETE /api/comments/:id` - コメント削除

### 7.4 タグAPI
- `GET /api/tags` - タグ一覧取得
- `POST /api/tags` - タグ作成
- `PUT /api/tags/:id` - タグ更新
- `DELETE /api/tags/:id` - タグ削除

### 7.5 チームAPI
- `GET /api/teams` - チーム一覧取得
- `POST /api/teams` - チーム作成
- `PUT /api/teams/:id` - チーム更新
- `DELETE /api/teams/:id` - チーム閉鎖

### 7.6 ユーザーAPI
- `GET /api/users` - ユーザー一覧取得
- `POST /api/users` - ユーザー作成
