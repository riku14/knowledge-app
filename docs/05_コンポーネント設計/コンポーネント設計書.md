# コンポーネント設計書

## 1. 概要

ナレッジ共有アプリケーションのReactコンポーネント設計書です。再利用可能なコンポーネントとページコンポーネントの構造を定義します。

## 3. 共通コンポーネント

### 3.1 Sidebar（サイドバー）

**ファイル**: `js/components/Sidebar.jsx`

**責務**: アプリケーションの主要ナビゲーションを提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| isOpen | boolean | ○ | サイドバーの開閉状態 |
| onClose | function | ○ | サイドバーを閉じるコールバック |
| currentPage | string | ○ | 現在のページID |
| onNavigate | function | ○ | ページ遷移コールバック |

**機能**:
- ロゴ・アプリ名表示
- 検索バー
- 新規記事作成ボタン
- ナビゲーションメニュー
- 所属チーム一覧（展開/折りたたみ）
- ユーザー情報表示
- 権限によるメニュー表示制御

**レスポンシブ**:
- PC: 固定表示（開閉可能）
- モバイル: オーバーレイ表示

---

**責務**: ページタイトル、パンくずリスト、ユーザーメニューを提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| onMenuClick | function | ○ | ハンバーガーメニュークリックコールバック |
| breadcrumbs | array | ○ | パンくずリストデータ |
| onNavigate | function | ○ | ページ遷移コールバック |
| onLogout | function | ○ | ログアウトコールバック |

**機能**:
- ハンバーガーメニュー（モバイル）
- パンくずリスト表示
- ユーザーメニュー（ドロップダウン）
  - ユーザー情報
  - ログアウト

---

### 3.3 ArticleCard（記事カード）

**ファイル**: `js/components/ArticleCard.jsx`

**責務**: 記事の概要情報をカード形式で表示

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| article | object | ○ | 記事情報オブジェクト |
| onNavigate | function | ○ | 記事詳細画面への遷移コールバック |
| onToggleFavorite | function | ○ | お気に入り追加/削除コールバック |

**表示内容**:
- カテゴリバッジ
- タグ一覧（最大3つ）
- タイトル
- 本文のプレビュー（一部抜粋）
- 投稿者情報（アバター、名前）
- 投稿日時
- 公開範囲バッジ
- お気に入りアイコン
- コメント数アイコン

**機能**:
- クリックで記事詳細画面へ遷移
- お気に入り追加/削除（アイコンクリック）
- ホバーエフェクト

---

### 3.4 Modal（モーダルダイアログ）

**ファイル**: `js/components/Modal.jsx`

**責務**: モーダルダイアログの表示を管理

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| isOpen | boolean | ○ | モーダルの表示状態 |
| onClose | function | ○ | モーダルを閉じるコールバック |
| title | string | ○ | モーダルタイトル |
| size | string | | サイズ（sm/md/lg/xl）デフォルト: md |
| children | node | ○ | モーダル内容 |

**サイズ**:
- `sm`: 最大幅 24rem (384px)
- `md`: 最大幅 28rem (448px)
- `lg`: 最大幅 32rem (512px)
- `xl`: 最大幅 36rem (576px)

**機能**:
- ESCキーで閉じる
- オーバーレイクリックで閉じる
- 閉じるボタン
- アニメーション

---

### 3.5 Toast（トースト通知）

**ファイル**: `js/components/Toast.jsx`

**責務**: 一時的な通知メッセージを表示

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| message | string | ○ | 通知メッセージ |
| type | string | | タイプ（success/error/info/warning）デフォルト: success |
| isVisible | boolean | ○ | 表示状態 |
| onClose | function | ○ | 閉じるコールバック |

**タイプ**:
- `success`: 緑色（成功）
- `error`: 赤色（エラー）
- `info`: 青色（情報）
- `warning`: 黄色（警告）

**機能**:
- 自動的に3秒後に閉じる
- 手動で閉じる（×ボタン）
- スライドイン/フェードアウトアニメーション
- 右上に表示

---

### 3.6 MarkdownEditor（Markdownエディタ）

**ファイル**: `js/components/MarkdownEditor.jsx`

**責務**: Markdown形式のテキスト編集を提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| value | string | ○ | エディタの値 |
| onChange | function | ○ | 値変更コールバック |
| placeholder | string | | プレースホルダー |

**機能**:
- ツールバー付きエディタ
  - 見出し（H1-H3）

  - コードブロック
  - リスト（順序あり/なし）

  - リンク、画像
- リアルタイムプレビュー（親コンポーネント側で実装）

## 5. コンポーネント設計原則

### 5.1 単一責任の原則

各コンポーネントは一つの責務のみを持つ

### 5.2 再利用性

共通コンポーネントは汎用的に設計し、複数のページで再利用可能にする

### 5.3 Props設計

- 必要な情報のみをPropsで受け取る
- コールバック関数で親コンポーネントと通信
- デフォルト値の設定

### 5.4 状態管理

- ローカル状態はuseStateで管理
- グローバル状態はApp.jsxで管理（将来はContext APIやReduxを検討）
