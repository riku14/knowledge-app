# コンポーネント設計書

## 1. 概要

ナレッジ共有アプリケーションのReactコンポーネント設計書です。再利用可能なコンポーネントとページコンポーネントの構造を定義します。

## 2. ディレクトリ構成

```
src/
├── components/     # 共通コンポーネント
│   ├── Layout.tsx
│   ├── Header.tsx
│   ├── Sidebar.tsx
│   ├── ArticleCard.tsx
│   ├── Modal.tsx
│   ├── Toast.tsx
│   └── MarkdownEditor.tsx
├── pages/          # ページコンポーネント
│   ├── LoginPage.tsx
│   ├── HomePage.tsx
│   ├── ArticleListPage.tsx
│   ├── ArticleDetailPage.tsx
│   ├── ArticleEditorPage.tsx
│   └── ... (その他のページ)
├── hooks/          # カスタムフック
│   ├── index.ts
│   └── useCurrentPageName.ts (例)
├── constants/      # 定数
│   ├── index.ts
│   └── menuItems.ts (例)
├── utils/          # ユーティリティ関数
│   ├── index.ts
│   └── formatDate.ts (例)
├── App.tsx         # アプリケーションのルートコンポーネント
├── main.tsx        # エントリーポイント
└── index.css       # グローバルスタイル
```

### 2.1 ディレクトリの役割

#### `components/`
- **用途**: 複数のページで再利用される共通コンポーネント
- **命名規則**: PascalCase（例: `Header.tsx`, `ArticleCard.tsx`）
- **例**: Layout, Header, Sidebar, ArticleCard, Modal, Toast

#### `pages/`
- **用途**: ルーティングで直接使用されるページコンポーネント
- **命名規則**: PascalCase + Pageサフィックス（例: `HomePage.tsx`, `LoginPage.tsx`）
- **例**: LoginPage, HomePage, ArticleListPage, ArticleDetailPage

#### `hooks/`
- **用途**: カスタムフック（再利用可能なロジック）
- **命名規則**: camelCase + useプレフィックス（例: `useCurrentPageName.ts`）
- **エクスポート**: `hooks/index.ts`から一括エクスポート

#### `constants/`
- **用途**: アプリケーション全体で使用する定数
- **命名規則**: camelCase（例: `menuItems.ts`, `routes.ts`）
- **エクスポート**: `constants/index.ts`から一括エクスポート

#### `utils/`
- **用途**: 純粋関数（ヘルパー関数）
- **命名規則**: camelCase（例: `formatDate.ts`, `validateInput.ts`）
- **エクスポート**: `utils/index.ts`から一括エクスポート

### 2.2 インポートルール

```typescript
// ❌ 悪い例: 相対パスが深い
import { Header } from '../../../components/Header'

// ✅ 良い例: index.ts経由でエクスポート
import { Header } from '@/components'
import { useCurrentPageName } from '@/hooks'
import { menuItems } from '@/constants'
```

各ディレクトリの`index.ts`から一括エクスポートすることで、インポートパスを簡潔に保つ。

## 3. 共通コンポーネント

### 3.1 Layout（レイアウト）

**ファイル**: `src/components/Layout.tsx`

**責務**: ログイン画面以外の全画面に適用される共通レイアウトを提供

**機能**:
- SidebarとHeaderを包含
- ページコンテンツエリアを提供（React Routerの`Outlet`を使用）

---

### 3.2 Sidebar（サイドバー）

**ファイル**: `src/components/Sidebar.tsx`

**責務**: アプリケーションの主要ナビゲーションを提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| isOpen | boolean | ○ | サイドバーの開閉状態 |
| onClose | function | ○ | サイドバーを閉じるコールバック |
| currentPage | string | ○ | 現在のページID |
| onNavigate | function | ○ | ページ遷移コールバック |

**機能**:
- ロゴ・アプリ名表示
- 検索バー
- 新規記事作成ボタン
- ナビゲーションメニュー
- 所属チーム一覧（展開/折りたたみ）
- ユーザー情報表示
- 権限によるメニュー表示制御

**レスポンシブ**:
- PC: 固定表示（開閉可能）
- モバイル: オーバーレイ表示

---

### 3.3 Header（ヘッダー）

**ファイル**: `src/components/Header.tsx`

**責務**: ページタイトル、パンくずリスト、ユーザーメニューを提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| onMenuClick | function | ○ | ハンバーガーメニュークリックコールバック |
| breadcrumbs | array | ○ | パンくずリストデータ |
| onNavigate | function | ○ | ページ遷移コールバック |
| onLogout | function | ○ | ログアウトコールバック |

**機能**:
- ハンバーガーメニュー（モバイル）
- パンくずリスト表示
- ユーザーメニュー（ドロップダウン）
  - ユーザー情報
  - ログアウト

---

### 3.4 ArticleCard（記事カード）

**ファイル**: `src/components/ArticleCard.tsx`

**責務**: 記事の概要情報をカード形式で表示

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| article | object | ○ | 記事情報オブジェクト |
| onNavigate | function | ○ | 記事詳細画面への遷移コールバック |
| onToggleFavorite | function | ○ | お気に入り追加/削除コールバック |

**表示内容**:
- カテゴリバッジ
- タグ一覧（最大3つ）
- タイトル
- 本文のプレビュー（一部抜粋）
- 投稿者情報（アバター、名前）
- 投稿日時
- 公開範囲バッジ
- お気に入りアイコン
- コメント数アイコン

**機能**:
- クリックで記事詳細画面へ遷移
- お気に入り追加/削除（アイコンクリック）
- ホバーエフェクト

---

### 3.5 Modal（モーダルダイアログ）

**ファイル**: `src/components/Modal.tsx`

**責務**: モーダルダイアログの表示を管理

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| isOpen | boolean | ○ | モーダルの表示状態 |
| onClose | function | ○ | モーダルを閉じるコールバック |
| title | string | ○ | モーダルタイトル |
| size | string | | サイズ（sm/md/lg/xl）デフォルト: md |
| children | node | ○ | モーダル内容 |

**サイズ**:
- `sm`: 最大幅 24rem (384px)
- `md`: 最大幅 28rem (448px)
- `lg`: 最大幅 32rem (512px)
- `xl`: 最大幅 36rem (576px)

**機能**:
- ESCキーで閉じる
- オーバーレイクリックで閉じる
- 閉じるボタン
- アニメーション

---

### 3.6 Toast（トースト通知）

**ファイル**: `src/components/Toast.tsx`

**責務**: 一時的な通知メッセージを表示

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| message | string | ○ | 通知メッセージ |
| type | string | | タイプ（success/error/info/warning）デフォルト: success |
| isVisible | boolean | ○ | 表示状態 |
| onClose | function | ○ | 閉じるコールバック |

**タイプ**:
- `success`: 緑色（成功）
- `error`: 赤色（エラー）
- `info`: 青色（情報）
- `warning`: 黄色（警告）

**機能**:
- 自動的に3秒後に閉じる
- 手動で閉じる（×ボタン）
- スライドイン/フェードアウトアニメーション
- 右上に表示

---

### 3.7 MarkdownEditor（Markdownエディタ）

**ファイル**: `src/components/MarkdownEditor.tsx`

**責務**: Markdown形式のテキスト編集を提供

**Props**:

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| value | string | ○ | エディタの値 |
| onChange | function | ○ | 値変更コールバック |
| placeholder | string | | プレースホルダー |

**機能**:
- ツールバー付きエディタ
  - 見出し（H1-H3）
  - 太字、斜体
  - コードブロック
  - リスト（順序あり/なし）

- リアルタイムプレビュー（親コンポーネント側で実装）

## 4. ページコンポーネント

- **SearchResultsPage**: 検索結果画面
- **FavoritesPage**: お気に入り一覧画面
- **TagManagementPage**: タグ管理画面
- **TeamManagementPage**: チーム管理画面
- **UserManagementPage**: ユーザー管理画面

各ページコンポーネントの詳細は画面設計書を参照してください。

## 5. コンポーネント設計原則

### 5.1 単一責任の原則

各コンポーネントは一つの責務のみを持つ

### 5.2 再利用性

共通コンポーネントは汎用的に設計し、複数のページで再利用可能にする

### 5.3 Props設計

- 必要な情報のみをPropsで受け取る
- コールバック関数で親コンポーネントと通信
- デフォルト値の設定

### 5.4 状態管理

- ローカル状態は`useState`で管理
- ルーティングはReact Router v7を使用
- `hooks/`ディレクトリにカスタムフックとして共通ロジックを切り出す
- グローバル状態は将来Context APIやReduxを検討

### 5.5 ファイル命名規則

- **コンポーネント**: PascalCase（例: `Header.tsx`, `ArticleCard.tsx`）
- **ページ**: PascalCase + Page（例: `HomePage.tsx`, `LoginPage.tsx`）
- **フック**: camelCase + useプレフィックス（例: `useCurrentPageName.ts`）
- **定数**: camelCase（例: `menuItems.ts`）
- **ユーティリティ**: camelCase（例: `formatDate.ts`）
