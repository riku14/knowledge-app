## TailwindCSS記載順序ルール

1. レイアウト
   - display (flex, grid, block, inline)
   - flex/grid設定 (flex-col, grid-cols-2)

2. 配置
   - position (absolute, relative, fixed)
   - 配置 (top, right, bottom, left)
   - z-index

3. サイズ
   - width (w-6, w-full)
   - height (h-6, h-full)
   - max-width, min-width
   - max-height, min-height

4. 余白
   - margin (m-_, mt-_, mb-_, mx-_, my-\*)
   - padding (p-_, pt-_, pb-_, px-_, py-\*)

5. スタイル
   - background (bg-\*)
   - border (border, border-_, rounded-_)
   - shadow

6. タイポグラフィ
   - font (font-_, text-_)
   - text-align
   - line-height
   - letter-spacing

7. エフェクト
   - opacity
   - cursor
   - transition
   - transform
