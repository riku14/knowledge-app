## 4. 統合テスト

### 4.1 API統合テスト

#### テスト例: 記事作成API

```javascript
describe('POST /api/articles', () => {
  test('認証済みユーザーが記事を作成できる', async () => {
    const token = await getAuthToken();
    const response = await request(app)
      .post('/api/articles')
      .set('Authorization', `Bearer ${token}`)
      .send({
        title: 'テスト記事',
        content: 'テスト内容',
        categoryId: 'cat1',
        scope: 'team',
        teamId: 'team1'
      });
    
    expect(response.status).toBe(201);
    expect(response.body.data.title).toBe('テスト記事');
  });

  test('未認証ユーザーは記事を作成できない', async () => {
    const response = await request(app)
      .post('/api/articles')
      .send({ ... });
    
    expect(response.status).toBe(401);
  });
});
```

## 5. E2Eテスト

### 5.1 テストシナリオ

#### シナリオ1: 記事作成フロー

```javascript
test('記事を作成して公開する', async ({ page }) => {
  // ログイン
  await page.goto('/');
  await page.fill('#userId', 'user1');
  await page.fill('#password', 'password');
  await page.click('button:has-text("ログイン")');
  
  // 記事作成画面へ
  await page.click('button:has-text("新規記事作成")');
  
  // フォーム入力
  await page.fill('input[name="title"]', 'E2Eテスト記事');
  await page.selectOption('select[name="category"]', 'cat1');
  await page.fill('textarea[name="content"]', '# テスト記事\n\n内容');
  
  // 投稿
  await page.click('button:has-text("投稿")');
  
  // 確認
  await expect(page.locator('.toast')).toContainText('記事を投稿しました');
});
```

### 5.2 主要なE2Eテストシナリオ

1. **ログインフロー**: ログイン → ホーム画面表示
2. **記事作成フロー**: 記事作成 → 下書き保存 → 編集 → 投稿
3. **承認フロー**: 記事投稿 → 承認待ち → 承認 → 公開
4. **検索フロー**: 検索実行 → 結果表示 → 記事詳細表示
5. **お気に入りフロー**: お気に入り追加 → お気に入り一覧表示
