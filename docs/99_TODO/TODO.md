## 📝 実装時の注意事項

1. **ステップバイステップで実装**
   - 各タスクは細かく分割して実装
   - 1つのステップが完了してから次に進む

2. **コンポーネントの再利用性**
   - 共通コンポーネントは再利用可能に設計
   - スタイリングはTailwind CSSを使用

3. **レスポンシブ対応**
   - PC、タブレット、モバイルすべてに対応
   - ブレークポイントは`lg:`（1024px）を使用

4. **型安全性**
   - TypeScriptの型定義を適切に使用
   - `src/types/`ディレクトリに型定義を追加

5. **モックデータ**
   - 現時点ではバックエンドがないため、モックデータを使用
   - `src/mockData/`ディレクトリに追加

6. **ルーティング**
   - React Routerを使用
   - `App.tsx`にルートを追加
