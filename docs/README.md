## 使い方

### Markdownビューアー

各ドキュメントはMarkdown形式で記述されています。以下のツールで閲覧できます：

- **Visual Studio Code**: Markdownプレビュー機能を使用
- **GitHub**: リポジトリにプッシュすると自動的にレンダリング
- **Markdownビューアー**: 各種Markdownビューアーアプリ

### Mermaid図の表示

ER図や画面遷移図はMermaid形式で記述されています。以下の方法で表示できます：

1. **Mermaid公式サイト**: https://mermaid.live/ にコードを貼り付けて表示
2. **VS Code拡張機能**: "Markdown Preview Mermaid Support" をインストール
3. **GitHub**: リポジトリにプッシュすると自動的にレンダリング
4. **専用ビューアー**: 各種Mermaidビューアーアプリ

### 画面キャプチャ画像

画面キャプチャ画像は `03_画面設計/画像/` ディレクトリに保存されています。
